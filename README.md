# CS Survival Quiz: Debugging Myths & Tips 🧠💻

An Android Jetpack Compose quiz app built for **CSC 371 – Mobile Application Development**.  
It combines beginner debugging myths with real programming tips — created from a student’s perspective.

---

## 🎯 Overview
This app challenges players with short computer science questions about debugging and coding best practices.  
It includes login, registration, validation, and a persistent score history saved locally on the phone.

---

## 🧩 Features

- **Splash screen** with app name and logo  
- **Login / Register** pages with data validation  
- **Quiz gameplay** with timer, skip, confirm dialog  
- **5+ questions** (single and multi-answer)  
- **Results screen** with streaks and performance  
- **Local storage** for quiz history (SharedPreferences)  
- **Consistent design** with background image and cards  

---

## 📱 Screens
| Screen | Description |
|---------|--------------|
| Splash | App logo + background with transition |
| Auth | Login or Register with field validation |
| Game | Timed quiz questions with confirm + skip |
| Results | Shows score, streak, and history options |
| History | Past scores saved locally |

---

## 🛠️ Tech Used
- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **SharedPreferences** for local data storage
- **Android Studio (Arctic Fox+)**
